# 主系統可靠性稽核（2026-09-21）

## 範圍與不變條件

以本機現有程式為準，檢查 Core／Application／Runtime／App 的資料保存、來源與輸出邊界、匯入、模型下載與生命週期、批次取消、共用排版器、Web bridge，以及 MCP transport、工作區協調與認證邊界。OCR／翻譯／上色的既有回歸測試一併執行。

- 不修改 WebUI 的 HTML、CSS、JavaScript、選單、按鈕或操作步驟。
- 不修改 MCP 白名單、socket 來源 IP 判斷、session header 或認證方式；既有請求大小上限改在接收階段提早執行。
- 不改專案／`.str` schema，不移轉使用者資料，不改 OCR、翻譯、校稿、遮罩或上色演算法。
- 不更新套件版本，不自動下載大型模型，不發布 GitHub、Release 或安裝包。

這是程式碼檢查及自動化回歸驗證，不等同所有模型、裝置、視覺操作與壓力情境均已實測。

## 已修正的問題

| 項目 | 原本風險 | 修正與驗證 |
| --- | --- | --- |
| 專案、索引、`.str` 保存 | 主檔遺失時不讀備份；損壞主檔可能輪替覆蓋健康備份 | 共用 `RecoverableFile`，保存前驗證 schema，只備份可解碼的舊主檔；測試損壞／遺失復原及無效 schema 不得覆寫 |
| 圖片寫入 | ImageIO 直接寫目的檔，中途失敗可能破壞舊預覽 | 共用 `AtomicFileWriter`，相同目錄暫存、完成後原子替換；測試失敗保留原檔、成功替換、提交失敗清理及 PNG 重讀 |
| 輸出路徑 | 上色檔名被串成子目錄；符號連結可讓新檔越出輸出根目錄 | 上色為同目錄的 `*-colorized.png`；共用逐段符號連結解析，測試未建立檔案、dangling link、循環連結與非法相對路徑 |
| 批次取消與去重 | `CancellationError` 不一定伴隨 `Task.isCancelled`，可能顯示完成；重算工作被普通工作去重 | 納入明確取消狀態及 `forceRecalculation`；兩種情境均有測試 |
| 跨 `await` 工作互斥 | actor 重入可能讓其他 MCP session 切換 service 工作區；排版等待者不能即時取消 | MCP 工具及動態資源、WebKit 排版器使用共用 FIFO gate；測試跨暫停互斥、錯誤釋放及等待者取消 |
| 模型載入失效 | 卸載或變更推論設定後，先前尚未完成的載入仍可能發布 runtime | 載入 generation 檢查及取消檢查；編譯驗證，實際大型模型載入／卸載競態尚未實測 |
| 下載完整性 | 預配置權重檔、缺少 shard、空檔或只有 Draft 仍可能判為已安裝 | 未完成標記、非空一般檔、設定 JSON 與權重索引檢查；測試標記、缺 shard、空檔與 Draft 隔離 |
| 選用模型附件 | 已安裝仍查遠端；選用附件的部分磁碟錯誤會阻擋主模型 | 完整安裝直接離線完成，附件失敗維持主模型可用，取消繼續傳遞；測試主模型與附件皆已安裝時不需要網路 |
| HTTP body 記憶體 | 累積完整 request body 後才檢查大小 | NIO handler 在累積前限制既有上限；測試 chunked、Content-Length、keep-alive 計數重設及既有 CIDR 規則 |
| 匯入與解壓 | 先等待程序退出、再讀 stderr，可能管線塞滿；失敗匯入留下新目錄 | 匯入與模型解壓共用有界診斷 runner；資料夾採逐項列舉，失敗清理僅限本次新目錄；大量 stderr 及保留既有檔案測試通過 |
| 外部 worker 取消 | 在已取消 Task 內忽略 sleep 錯誤，形成忙迴圈並跳過正常終止寬限期 | 獨立清理 Task 保留等待及最後強制終止；以忽略 TERM 的測試程序驗證取消後仍有寬限期 |
| bridge 數值 | 接受 NaN／Infinity；整數轉換可能截斷、溢位或把錯誤當作未提供 | 有限數值與精確整數轉換；測試一般值、Int 上界、超範圍及非有限值；MCP 超範圍整數明確拒絕 |

## 優化取捨

- 已安裝模型不重複查 metadata、資料夾匯入不先收集完整檔案陣列、解壓診斷只保留 64 KiB；這些是減少不必要 I/O 或記憶體配置，未宣稱推論吞吐提升。
- `RecoverableFile` 的同步鎖保護程序內多個 repository instance 的讀寫交易，不是跨程序鎖，也不能解決語意上的過期快照覆寫。
- MCP 操作暫時採 service 層級互斥，優先保護工作區一致性；不同工作區的請求也會排隊，不宣稱增加 MCP 並行吞吐。
- 圖片採相同目錄的暫存檔，不額外保留整張 PNG 的記憶體副本。原子替換避免讀者看見半寫入檔案，不宣稱涵蓋斷電時所有儲存裝置的耐久性保證。
- 符號連結檢查處理正常使用下的路徑邊界，不是用來抵禦另一個本機程序在檢查與寫入之間惡意置換檔案系統。
